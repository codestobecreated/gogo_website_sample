# GOGO Camping — Jawadhu Hills Website

A responsive, aesthetic outdoor camping landing page for **GOGO Camping** located in Jawadhu Hills (Eastern Ghats, Tamil Nadu).

## 🏕️ Features
- **Modern Typography**: Fraunces (Headings), Caveat (Handwritten accents), and DM Sans (Body).
- **Curated Color Palette**:
  - Button Green: `#173D2B`
  - Button Orange: `#A8462D`
  - Button Cream: `#F8F4EA`
  - Overall BG: `#F1EBDD`
  - Footer BG: `#E6DECD`
  - Text Green: `#85831A`
  - Icons: `#A8462D`
- **Interactive Booking Widget**: Live price calculator & confirmation modal.
- **Astro-Camping Section & Modals**: Vainu Bappu Observatory guide & ambient camp sounds.
- **Pure Glassmorphism & Overlays**: Real frosted glass card over cosmic night sky.

## 🚀 How to Run Locally
Open `index.html` directly in any web browser.
